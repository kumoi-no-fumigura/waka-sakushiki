## 作品について

喜撰の撰と称する歌式で、「喜撰式」とも呼ばれる。歌の病（岸樹・風燭・浪船・落花）を説き、後半には歌に用いる異名を挙げる。ここの本文は国文学研究資料館所蔵の写本。

## 本文の作り方

国文学研究資料館の公開画像を、国立国会図書館の NDL古典籍OCR-Lite でテキスト化し、原本のページごとに段落に分けました。写本の崩し字の OCR なので、誤りが多く残っています。

## 誤りを見つけたら
